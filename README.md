# 舞台吊杆连续碰撞预演

纯前端单页应用：在俯视画布中编辑两根平移吊杆和一个静态禁区，并在共同校核闭区间内给出**可复核的首次接触**。技术栈为 TypeScript + React + Vite + Canvas API；所有几何判定均使用 `bigint` 分子/分母表示的精确有理数，不进行时间采样。

## 运行

### Docker Compose（推荐）

```bash
# 默认宿主端口 8080
docker compose up --build

# 覆盖宿主端口
WEB_PORT=3000 docker compose up --build
```

打开 http://localhost:8080 （或 `WEB_PORT` 指定的端口）。容器内部固定使用 Vite 预览端口 4173。

一次性完整校核（Vitest + Playwright，容器退出即结束）：

```bash
docker compose --profile verify run --rm verify
```

### 本地开发

```bash
npm ci
npm run dev        # 开发服务器
npm run build      # TypeScript 检查 + 生产构建
npm run preview    # 本地预览生产包
```

## 测试

```bash
npm run test:unit  # Vitest：有理数、输入校验、连续碰撞与裁决
npx playwright install chromium
npm run test:e2e   # Playwright：真实浏览器链路、画布和表单交互
```

`npm run verify:ci` 会依次运行单元测试和端到端测试；Docker 的 `verify` 服务使用同一命令。

## 输入规则

- 吊杆局部轮廓和禁区世界轮廓：
  - 至少 3 个互异整数顶点；
  - 顶点按**顺时针**录入；
  - 每个非边端顶点均严格位于每条有向边右侧，因此拒绝连续共线、零面积、非凸或自交轮廓。
- 吊杆关键帧：
  - 时间为严格递增整数毫秒；
  - 平移锚点位置为整数毫米；
  - 相邻关键帧之间仅线性平移，不旋转、不形变。
- 共同校核闭区间取两根吊杆时间轴的 `min(首帧时间)` 到 `max(末帧时间)`；
  吊杆在自身首帧之前保持首帧端点姿态，在末帧之后保持末帧端点姿态。
- 非法输入不会被清空：字段保留用户文本，同时旧结论立即消失，第一个错误字段获得焦点，错误列表可继续定位其它字段。

## 精确连续碰撞算法

每根吊杆的锚点在各自相邻关键帧间是时间的一次函数。取两吊杆关键帧时间的并集切分共同区间，则在每个时间片内：

- 每条边的起点为 `P₀ + V·s`，其中 `s∈[0,1]` 为该片内归一化时间；
- 静态禁区的速度为零；
- 对每一对边，求解两条闭线段是否存在 `s, α, β ∈ [0,1]`：
  `A(s)+αU = C(s)+βV`。

非平行边得到关于 `s, α, β` 的线性等式/不等式组；平行边额外处理共线投影区间。所有系数和结果均为 `bigint` 有理数，通过一次函数不等式的精确上下界求交得到接触时间区间，**没有任何离散采样或浮点比较**。

接触包括：

- 边内部横交；
- 顶点碰到边内部；
- 顶点与顶点接触；
- 共线边的点接触或区间重合；
- 区间起点已整体重叠且边界无交点（此时按规则在最小对象对中取双方最小边号 E1/E1）。

首次时间会约分后显示。同一最早时刻的所有接触按：

1. 对象编号有序对：`(1,2) < (1,3) < (2,3)`；
2. 对应对象边的录入序号对；

做字典序排列。顶点同时触及多条边、或共线重合涉及的全部边组合都会枚举，不会只保留一个接触。

只有闭区间内所有对象对全程严格分离时，界面才显示“安全”；任何边界接触（距离恰为零）都判定违规。

## 占用包络（地面扫掠区域）

在回放控制旁选择一根吊杆并输入起止毫秒（整数、非逆序且位于共同校核闭区间内），点“确认计算占用包络”后：

- 区间端点可落在关键帧之间：几何层在端点处复用该时刻的分段线性插值姿态（端点外保持端点姿态），每个分段内凸轮廓沿位移线段扫掠，扫掠体边界由两姿态顶点的精确凸包（保留共线边界点）给出；
- 各段扫掠多边形全部用 `bigint` 有理数切分、求交（相交、T 接、共线重合），半边排布按极角稳定排序，覆盖数用中点符号无穷小平移 + 水平射线绕数精确计算，折返、共线重合与闭环自覆盖自然按重数归一；
- 输出**顺时针外环**与**逆时针孔洞**，无重复零长边；环从字典序最小顶点起排并按最小顶点稳定排序，每条边在同向重合来源中按“最早时刻 → 段序 → 轮廓边先于顶点 → 序号”裁决唯一来源（源关键帧段 + 轮廓边 E 或顶点 V）；
- 结果区显示约分后的精确面积（mm²）和外环/孔洞数量，包络以青色叠加在同一画布（孔洞镂空）；
- 点击任一包络边：回放跳到该边首次出现的最早精确时刻，并在画布高亮对应源轮廓特征（边或顶点），结果区同步展示精确时刻、源段区间与来源；
- 起止值非整数、逆序或越界时：保留输入文本、立即移除包络、首个错误字段聚焦，但**不清除**当前碰撞结论；修正后再次确认即可恢复。

包络的输入校验不通过不会影响原有首次接触结论、“跳到首次接触”和回放控制。

## 界面

- 左侧 Canvas：实时绘制两根吊杆、静态禁区、网格以及首次接触点/接触段；
  - 可直接拖动红色圆形手柄编辑禁区顶点，拖动方形关键帧锚点（自动吸附整数）；
  - 吊杆外形顶点属于各自局部坐标系，请使用下方整数表单精确编辑；
- 时间滑条和“回放”可在共同区间内连续复查姿态；“跳到首次接触”直接定位精确时刻；
- 右侧结论显示约分后的精确时间（整数或 `分子/分母`）、对象对、双方边号和接触姿态；
- 下方三个编辑卡分别维护两根吊杆的局部轮廓/关键帧和静态禁区顶点。
